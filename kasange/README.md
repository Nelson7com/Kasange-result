# Kasange Secondary School — Results Frontend

Frontend demo for the Kasange Secondary School Results Management System.

## Included
- Teacher Login with fixed teacher password
- Teacher profile + photo upload
- Form One to Form Six class selection
- Class image placeholders
- Subject, term, year and stream information with validation
- Student results entry
- Add/delete students
- Automatic grades
- Review before submit
- Submit to Admin workflow
- Results history from Supabase storage
- Admin login with fixed admin password
- Admin profile + photo upload
- Admin dashboard, approval, viewing and delete workflow
- Light/Dark mode
- Responsive desktop/mobile layout

## Supabase-only storage
Use the Supabase JavaScript SDK and configure the values in app.js.

CREATE DATABASE TABLE
```sql
create table if not exists public.results (
  id bigint generated by default as identity primary key,
  class text not null,
  teacher text not null,
  subject text not null,
  term text not null,
  year text not null,
  stream text not null default 'A',
  count integer not null default 0,
  status text not null default 'Pending Admin',
  date text not null,
  rows jsonb not null default '[]'::jsonb
);
```

## Run
Open `index.html` in Chrome after placing the Supabase URL and anon key in app.js.

This is a frontend prototype and the data layer is connected to Supabase only.
